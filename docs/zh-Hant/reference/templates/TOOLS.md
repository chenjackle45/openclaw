# TOOLS.md - 本地筆記

Skills 定義工具的*運作方式*。這個檔案是為了*你的*特定設定——那些屬於你設置環境的獨特內容。

## 記錄哪些內容

例如：

- 攝影機名稱與位置
- SSH 主機與別名
- 偏好的 TTS 語音
- 喇叭／房間名稱
- 設備暱稱
- 任何環境特定的設定

## 範例

```markdown
### 攝影機

- living-room → 主要區域，180° 廣角
- front-door → 入口，動作觸發

### SSH

- home-server → 192.168.1.100，使用者：admin

### TTS

- 偏好語音：「Nova」（溫暖、略帶英國腔）
- 預設喇叭：廚房 HomePod
```

## 為什麼要分開存放？

Skills 是共享的。你的設置是私人的。將它們分開意味著你可以更新 Skills 而不會遺失筆記，也可以共享 Skills 而不會洩露基礎設施。
